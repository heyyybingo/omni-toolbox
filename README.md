# OmniToolbox

> 面向开发者、设计人员与文档办公的高效纯前端工具套件，集成格式互转、文档处理、视觉媒体与代码辅助工具。

## 核心功能矩阵

### 1. 开发者常用工具
- **JSON ↔ YAML 互转**：支持 JSON 与 YAML 结构双向互换、缩进层级配置（2/4 空格）、语法实时校验与错误定位。
- **JSON ↔ CSV 互转**：支持对象/数组与表格文件双向互换、多分隔符选择（逗号、分号、Tab 制表符）、一键双向内容对调。
- **JSON 转 TypeScript**：递归分析 JSON 数据结构推导 TS 接口与类型声明，支持配置根接口名、`export` 前缀、`type` 别名及 `readonly` 只读修饰符。
- **文本 / JSON 差异对比**：支持按行（Lines）与按词（Words）两种比对维度，直观呈现内容变更与行内差异。
- **正则表达式测试**：实时语法高亮、匹配组结构化解析，提供 9 种高频预设规则及实时文本替换预览。
- **编码与哈希**：Base64 编码/解码、URL 编解码、哈希校验（SHA-1、SHA-256、SHA-512）、Unix 时间戳转换、UUID v4 批量生成。
- **图形与设计**：SVG 实时预览与属性配置、QR 码生成与容错率调节、色彩模型互转（HEX / RGB / HSL）。

### 2. 图像处理与检视
- **格式互转与转换**：支持 PNG、JPEG、WEBP、AVIF、HEIC 等主流图像互转，保留原始比例与色彩配置。
- **压缩与缩放**：质量参数精细调节、像素尺寸自适应重采样。
- **视觉效果校准台**：图像处理工具内嵌 A/B 分割滑块对比、原图/效果图双视窗实时对比与体积变动估算。
- **Favicon / 网站图标打包**：一键生成全套标准尺寸（16×16、32×32、48×48、180×180、192×192、512×512 PNG）、多分辨率二进制打包的 `favicon.ico`、`site.webmanifest` 与 HTML 标签清单。
- **EXIF 元数据检视**：深度解析曝光快门、ISO、相机镜头型号、拍摄时间与 GPS 地理位置（含地图链接），支持过滤检索与元数据导出。
- **图形裁剪、拼接与分割**：支持长图纵横拼接、网格宫格切图与多模式水印添加。

### 3. PDF 与文档引擎
- **PDF 页面重组**：合并多个 PDF、拆分提取指定页码范围、旋转校准页面方向。
- **版面组织与水印**：批量插入文字/图章水印、页眉页脚与动态页码格式设置。
- **安全与表单**：PDF 密码保护与权限配置（禁止打印/复制）、加密文档解密验证、交互式表单字段填充。
- **内容提取**：PDF 转高分辨率图像序列、抽取纯文本内容与大纲书签目录重构。

### 4. 音频与视频
- **视频转 GIF**：提取视频指定时间段帧序列、配置生成宽度与帧率。
- **封面截取与裁剪**：精准定位时间轴截取视频封面帧、按指定时段修剪视频。
- **音频格式转码**：WAV、MP3、FLAC 等音频编码格式转换、采样率与声道调节。
- **音轨提取与修剪**：从视频中无损剥离音轨、音频片段精准裁剪。

## 交互设计规范

1. **沉浸式多页签工作台**：
   - 顶部工具页签支持多开与独立会话保存；
   - 超长页签采用自适应动态测量，折叠按钮（`··· +N`）紧随可视页签后方排布，悬停或点击呼出浮动 Popover 快捷切换或删除；
   - 支持全流程放大工作区，铺满中央视口并保留标准边距，大屏操作更从容。
2. **居中弹出层（Lightbox Modal）**：
   - 图像效果校准、文件产物检视统一采用宽屏居中弹出层呈现，消除边缘侧栏挤压，支持点击遮罩或 `Esc` 键退出。
3. **极简且严格的功能布局**：
   - 工作台统一遵循「文件管理 → 参数配置与校准 → 操作栏 → 产物列表」标准流；
   - 消除重复功能按钮，确保同类型交互行为高度一致。

## 本地开发与构建

### 环境要求
- Node.js >= 18.0.0
- npm >= 9.0.0

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```
开发服务器默认运行于 `http://localhost:5173`。

### 运行单元测试
```bash
npm test
```

### 生产环境打包
```bash
npm run build
```
打包产物将输出至 `./dist` 目录。

## CI/CD 与 GitHub Pages 部署

本项目包含基于 GitHub Actions 的自动化流水线：
- **触发条件**：向 `main` 分支提交或合并代码（`push`）
- **流程任务**：
  1. 自动化检出代码与初始化 Node 20 运行环境；
  2. 运行单元测试集，保障核心逻辑与格式算法质量；
  3. 执行 `vite build` 生产构建，相对路径打包；
  4. 自动部署至 GitHub Pages 静态站点。
